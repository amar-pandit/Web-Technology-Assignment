# Question 1 - Student Registration Form

Technology: HTML, CSS, JavaScript (no server needed).

## Files
- `index.html` - form structure
- `style.css`  - styling and validation states
- `script.js`  - client-side validation

## How to run
Open `index.html` in any modern browser (double-click it).

## Validation implemented
- Required fields: name, roll number, email, course, password, confirm password, file
- Email format check
- Password strength: 8+ characters with lowercase, uppercase, digit and special character, with a live strength meter
- Password confirmation must match
- File upload: JPG/PNG/PDF only, maximum 2 MB
